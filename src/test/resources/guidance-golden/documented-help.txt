# help
Pickleball Workbench. help <command> prints usage. help <flag> prints that flag.
exit 0 ok, 1 failed, 2 usage. --json is one JSON object and no preamble.
help is always available on the thin controller jar and does not load Jackson.
decide: discover, then plan, then run. plan lists the scenarios. validate checks steps and does not run. run is confirm, or isolate then execute-step.
Timing is .pickleball/runs/<id>/launch-timing.txt. A cache hit skips Maven. Stderr timing only when PKB_WORKBENCH_TIMING=1 or -Dpkb_workbench_timing=true.
Do not pass pkb_run_profile. Do not open the GUI to test yourself. isolate is the headless session.

# help validate
Usage: validate [--tags=<expr>] [--name=<regex>] [--run-id=<id>] [--max-steps=<n>] [--all]
Reports undefined steps, ambiguous glue, and unresolved RUN SCENARIO targets. Outline rows are expanded. Core steps count as defined. A long suite prints progress and stops at a step cap unless --max-steps or --all is set, and reports how many scenarios were skipped. Runs nothing. A flag this command does not use, including --quiet, is rejected with error: and fix:.
