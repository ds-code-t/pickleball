# Pickleball project rule

Always read and follow `/AGENTS.md`.

For functionality changes, also read `/docs/agent/feature-map.md` and use the repository's implementation, tests, Maven consumer scenarios, test-site resources, and documentation as persistent project context.

A consumer-visible change is incomplete until applicable implementation, tests, executable consumer examples, documentation, feature-map entries, and validation have been addressed.

Do not ask the user to repeat the project setup already recorded in the repository.
