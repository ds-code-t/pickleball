## Decisions and full specs per phase

### Phase 1 (W1): Contracts + AffinityScorer + OneMatch + BoxCaps + SectionDetector
Create the three contract types with pass-through defaults for PreMapLookup. Implement real AffinityScorer over offline DomNode tree:
- Factors and default weights: distance 0.30 (normalized Euclidean + reading-order alignment), role compatibility 0.20, text similarity 0.15 (token Jaccard + Levenshtein), section co-membership 0.10, `for`/`aria-labelledby` boost +0.20, negative RelationTerm penalties −0.25 each.
- Returns explainable parts map.
BoxCaps: config keys `pkb.premap.box.maxArea` (default 1_000_000 or 90% viewport), `maxWidth`, `maxHeight`. Oversized excluded.
OneMatch: exactly one or CdpException with candidate list + scores/why.
SectionDetector: nested sections from h1–h6, ARIA landmarks/roles, forms, dialogs, tables, desktop panes/groups.
**Tests:** AffinityScoreTest, OneMatchTest, BoxCapTest, SectionDetectionTest (exact commands in roadmap).
**Docs:** start `docs/snapshot.md`.
**Acceptance:** compiles; scores explainable on fixtures; pass-through does not alter current Query behaviour.

### Phase 2 (W1): CompositeSnapshot model + schema
`CompositeSnapshot` with screenshot (base64 or path), structure DomNode, pageSource, xpathIndex Map, viewportMap, embedded preMap. JSON round-trip. Additive only on control-api types.
Document full schema in `docs/snapshot.md`.
**Tests:** CompositeSnapshotModelTest.
**Acceptance:** serializes; docs match code.

### Phase 3 (W1): Desktop producers
Extend DesktopTree / WindowsUia / MacAccessibility / AtSpi to capture screenshot (platform-native) + structure + bounds and produce CompositeSnapshot including pre-map.
**Tests:** DesktopSnapshotTest (fixture always; live skip + proof if bus/permissions missing).
**CLI-first:** run `domengine` CLI on fixture and show combined artifact output before further wiring.
**Logging:** existing EngineLog, toggleable, date-stamped, size-capped.

### Phase 4 (W1): PreMapBuilder offline
`PreMapBuilder` always invoked: affinity bindings, nested sections, capped boxes, XPath indexes, image/colour features (reuse TemplateMatch). Store in CompositeSnapshot.
**Tests:** PreMapTest.
**Acceptance:** every snapshot has full pre-map; runtime still pass-through.

### Phase 5 (W2): Browser producers
Wire Chrome/Chromium/Edge via G1 CdpAdapter/BrowserFacade and Firefox via BidiAdapter. Consume D9 frame paths and D10 row states. Full CompositeSnapshot (screenshot + tree + source + XPaths + viewport + pre-map). No reflective executeCdpCommand.

**Gate:** engine-defects Phase 4/5 + G1 adapters on origin/3.0.0. If not present, finish W1, record waiting, stop.
**CLI-first:** CLI live Chrome snapshot shows full artifact. Every protocol fallback logs WARN once per run + reason.
