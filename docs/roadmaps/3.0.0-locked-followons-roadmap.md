## Design decisions

**Opt-in only.** Grid drivers, ONNX Runtime, and the OCR model are never on the default classpath and never download during build, test, CI, or consumer runs. A user-run `setup` verb prints the license and source URL first, then downloads a pinned version and verifies its checksum. Code loads them reflectively; absent means a clear "not installed" result with a fix line.

**Playwright as a normal dependency.** Playwright for Java (with its driver-bundle) is a normal `implementation` dependency that appears in the published POM. It is not shaded or copied into pickleball's jar, and a check fails the build if its classes appear there. Playwright is always created with `PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1`, never runs `install`, and only connects over CDP to a browser that already exists.

**Attach order.** One `attach` entry point keeps the existing `attach --target=` CDP join and adds, in order: channel (`--cdp-endpoint=chrome|msedge|...`), the official Playwright extension (token from `PLAYWRIGHT_MCP_EXTENSION_TOKEN`, treated as a secret and redacted), explicit endpoints plus localhost-only discovery of the current user's own DevToolsActivePort files, and last a `relaunch-with-debug --confirm`. Nothing reads other users' profiles, cookies, or passwords, and nothing injects into other processes.

**Human mode is input, not a fence.** Queries may default to the human exposure. Human mode governs mouse and keyboard input only; stepping outside the human view is never a test failure.

**CLI first, logged.** Every new verb is registered in the CLI coverage gates, help, inventory, and MCP forwarders. New code uses the per-entity toggleable logging.
