## Decisions

### Row 1 — Single browser facade over Selenium, Playwright and raw CDP, wide version ranges
**Decision:** Introduce thin `tools.dscode.browser.BrowserFacade` interface. Adapters: `SeleniumAdapter` (scripted default lifecycle/elements), `PlaywrightAdapter` (optional scripted, wide range `[1.40.0,2.0.0)`), `CdpAdapter` (Chromium-family agent/direct), `BidiAdapter` (Firefox agent/direct). `ProtocolSelector.forDriver(WebDriver)` returns the appropriate protocol adapter or Selenium fallback. Facade methods include `send(method, params)`, `evaluateIsolated(worldName, fn, args)`, `addPreload(script)`, `addBinding(name, listener)`, `screenshot(options)`, `frameTree()`. Selenium range can be widened later; current pin stays until W3 if needed.
**Approach:** New package with interfaces first (compile-clean stubs), then full adapters. G3 producers and G4 popup call only these.
**Files:** new `src/main/java/tools/dscode/browser/*`. `build.gradle` dep block for Playwright (shared-with-care).
**Tests:** `BrowserFacadeTest`, `ProtocolSelectorTest`, `SeleniumAdapterTest`, `PlaywrightAdapterTest`, `CdpAdapterTest`, `BidiAdapterTest`.
**Docs:** `docs/configuration.md` browser/protocol rows, `docs/direct-control-handoff.md`.

### Row 2 — Libraries default for scripted; direct protocols for agents and narrow gaps; every fallback logs a warning
**Decision:** Reverse current default. Scripted element path becomes library adapters via the facade. `pkb_composite` meanings after flip: `off` = pure Selenium (no facade), `auto`/`library` = library path (Selenium or Playwright if selected), `agent` or agent sessions = direct CDP/BiDi. Any scripted use of direct protocols (narrow gaps only) logs exactly one WARN per run and reason. Existing consumers and Gherkin unchanged.
**Approach:** Flip in `CompositeMode`/`CompositeRuntime`/`ElementOperations` after engine-defects Phase 8. Agent sessions bypass via `AgentProtocolController`.
**Files:** `CompositeMode.java`, `CompositeRuntime.java`, `ElementOperations.java` (W3 only).
**Tests:** `DefaultPathTest`, `FallbackWarnTest`, `LibraryDefaultTest`.
**Docs:** all places stating composite/CDP as scripted default.

### Row 3 — Java owns agent protocol control behind a separate agent-only boundary
**Decision:** `AgentProtocolController` (Java) is the only entry to CdpAdapter/BidiAdapter for agents. Behind MCP. Scripted `ElementOperations` and library paths never call direct protocol methods.
**Approach:** New controller; MCP handlers delegate to it; guards in ElementOperations.
**Files:** new `AgentProtocolController.java`, MCP handlers, ElementOperations guard (W3).
**Tests:** `AgentBoundaryTest`, `AgentProtocolControllerTest`.
**Docs:** `docs/dynamic-control-api.md`, `AGENTS.md` (in-place).

### Row 4 — WebDriver BiDi is the Firefox protocol path
**Decision:** `BidiAdapter` implements Firefox path using Selenium's BiDi client or raw WebSocket as needed. Detection in ProtocolSelector. Equivalents for preload (`script.addPreloadScript`), isolated eval, channels.
**Approach:** Full BidiAdapter in W1; used for agent and PageSurfaces on Firefox.
**Files:** `BidiAdapter.java`.
**Tests:** `FirefoxBidiTest` (live or unit with fake).
**Docs:** configuration.md browser section.

### Row 5 — MCP server is the single agent entry point with predefined, parameterized commands
**Decision:** MCP is the sole public agent entry. Registry of `McpCommand` (name, JSON-schema params, handler). Predefined: query, click, type, snapshot (returns G3 `CompositeSnapshot` JSON; G3 owns schema), observe, launch, surfaces, etc. Other paths (control API, CLI, Workbench) become internal. G4 registers popup commands without editing G1 server classes.
**Approach:** Expand existing MCP servers with registry pattern in W1.
**Files:** `dom-engine/.../mcp/McpServer.java`, `pickleball-workbench/.../mcp/*`.
**Tests:** `McpCommandRegistryTest`, `McpSnapshotCommandTest`.
**Docs:** `docs/pickleball-workbench.md`, `docs/dynamic-control-api.md`.

### Addendum A — PageSurfaces to direct CDP/BiDi by default
**Decision:** PageSurfaces (html-write/replace/insert/overlay/remove/cleanup and overlay event capture) move to direct CDP by default on Chromium (`Page.createIsolatedWorld`, `Page.addScriptToEvaluateOnNewDocument`, `Runtime.addBinding` for push events with no polling, `DOM.*` for structural writes) and WebDriver BiDi on Firefox (`script.addPreloadScript`, sandboxed `script.callFunction`, channels). Selenium `executeScript` only as a logged last-resort fallback (one WARN per run + reason). Keep every existing sanitizing, labeling, undo and cleanup behaviour and tests (`AgentLiveFixTest`, `LiveChromeCdpTest`, `SurfaceIdChild`, `DomAccessGuardTest`).
**Approach:** Prefer adapters in PageSurfaces after W3 gate. Shared assets via SurfaceAssets loader.
**Files:** `PageSurfaces.java`, adapters, new `SurfaceAssets`.
**Tests:** existing plus `IsolatedWorldTest`, `BindingEventTest`, `PageSurfacesFallbackTest`.
**Docs:** `docs/direct-control-handoff.md`, `docs/configuration.md`.
