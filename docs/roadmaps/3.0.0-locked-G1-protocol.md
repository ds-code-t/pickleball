## Decisions

Every item is 100% implemented by some phase. No optional phases, no deferrals.

- **Row 1 — Single browser facade:** Introduce thin `BrowserFacade` in new package `tools.dscode.browser`. `ProtocolSelector.forDriver(WebDriver)` selects adapter: `SeleniumAdapter` (scripted library default), `PlaywrightAdapter` (optional, Gradle constraint `[1.40.0, 2.0.0)`), `CdpAdapter` (Chromium own socket), `BidiAdapter` (Firefox). Minimum methods: `send(String method, Map params)`, `evaluateIsolated(String worldName, String fn, Object... args)`, `addPreload(String script)`, `addBinding(String name, BindingListener listener)`, `screenshot(Map options)`, `frameTree()`. Plus lifecycle/find/click/type for library adapters. Wide version ranges via Gradle. G3 producers and G4 popup consume only these (never reflective `executeCdpCommand`).
- **Row 2 — Libraries default:** Reverse current. `pkb_composite` unset/`auto`/`off` (default) uses library adapters (SeleniumAdapter primary; Playwright if present). `on` forces Java engine for compatibility (INFO log). Direct CDP/BiDi only via `AgentProtocolController` for agent/MCP sessions or explicit narrow-gap flags. Every scripted fallback to direct protocols logs WARN once per run with reason. Narrow gaps allowed: PageSurfaces isolated injection, specific agent-only ops. Existing consumers keep working; no Gherkin changes. Scripted `ElementOperations` never call direct protocols.
- **Row 3 — Agent-only boundary:** `AgentProtocolController` (in `tools.dscode.browser`) owns all direct protocol control. Only MCP handlers call it. Scripted paths use library adapters exclusively; guards enforce this.
- **Row 4 — WebDriver BiDi for Firefox:** `BidiAdapter` implements Firefox path using WebDriver BiDi (`script.addPreloadScript`, sandboxed `script.callFunction`, channels). Chrome/Chromium/Edge use `CdpAdapter`. Detection in `ProtocolSelector`.
- **Row 5 — MCP single agent entry:** MCP servers (dom-engine + workbench) become the sole public agent entry via a registry of `McpCommand` (record/interface: name, JSON-schema params, handler). Predefined parameterized commands: query, click, type, snapshot, observe, launch, surfaces, plus extensible. Snapshot returns G3 `CompositeSnapshot` JSON (G3 owns schema). CLI/control API/Workbench become internal or forwarders. G4 adds popup commands by registering its own classes (no edit to G1 server classes).
- **Addendum A — PageSurfaces to direct CDP/BiDi:** On Chromium default to `CdpAdapter`: `Page.createIsolatedWorld`, `Page.addScriptToEvaluateOnNewDocument`, `Runtime.addBinding` (push events, no polling), `DOM.*` for structural writes. On Firefox: BiDi equivalents. Selenium `executeScript` only as logged last-resort fallback (WARN). Preserve all sanitizing, labeling, undo, cleanup behaviour and tests (`AgentLiveFixTest`, `LiveChromeCdpTest`, `SurfaceIdChild`, `DomAccessGuardTest`). Shared HTML/CSS/JS assets via `SurfaceAssets` loader (G4 popup reuses).

**Coexistence with Java engine:** Scripted default becomes library. Java engine remains available for explicit `pkb_composite=on` or agent path. Engine-defects page-target pinning (`CompositeRuntime.focusPage`/`focusedCdp`) is consumed, not reimplemented. Fallback logs WARN.

**Contracts G1 consumes (must honor during implementation):**
- **6 (G3 snapshot entry point).** The MCP `snapshot` command returns G3's `CompositeSnapshot` JSON unchanged. Once G3 lands them on `origin/3.0.0`, it calls `dev.domengine.snapshot.CompositeSnapshots.browser` / `.desktop` / `.offline` (in `dom-engine`) or `tools.dscode.common.seleniumextensions.SnapshotProducers.page` (in root). Phase 3 may ship a schema-shaped placeholder only until those methods exist; replace the placeholder as soon as they land.
- **8 (G4 `AgentSurfaceRouter` hook).** G4 owns `tools.dscode.common.agentsurface.AgentSurfaceRouter.route(...)` and adds exactly one guarded line at the top of the `AgentControl.execute` try block: `Optional<Result> routed = AgentSurfaceRouter.route(project, runId, op, values, agentId); if (routed.isPresent()) return routed.get();`. G1 keeps that line through its W3 edits.
- **9 (G4 `PopupSurfaceBridge`).** G4 creates `tools.dscode.common.agentcontrol.PopupSurfaceBridge` with public statics `neutralize(html)`, `label(html, kind)`, `sentence(kind)`, `recordInput(project, runId, event)`, `agentRoot(project, runId)`, `appendCapped(file, line)`, `hasBrowserPage(project, runId)` delegating to package-private `PageSurfaces` / `AgentStore` / `WindowRegistry` helpers. G1 keeps those signatures, or updates the bridge in the same commit that changes them.
