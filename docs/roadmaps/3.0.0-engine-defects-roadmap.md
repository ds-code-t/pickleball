# 3.0.0 Engine Defects Roadmap

**Status:** Mandatory phased plan. Design locked in docs/maintainer/3.0.0-engine-defects-design.md.  
**Branch:** 3.0.0 only. Version stays 3.0.0. No force-push, no tags, no releases.

All phases are mandatory. Each lists functionality, docs, and targeted tests. CLI-first and logging checklist applies to every phase. Scoreboard placeholders appear at the end of each phase.

## Phase 1 — Page/tab attach, loud fallback, unified lookup (D1, G1, G2)

**Functionality:** Resolve page target on attach/join for all paths (Cucumber, native, Workbench, direct control). Loud configurable WARN on auto Selenium fallback. Unify lookup order to pkb_composite_bin, then COMPOSITE_BIN, then bundled Java engine (unless rust requested). Optional INFO on explicit Rust override.

**Docs:** Update design notes if tip differs; update any remaining stale locator Javadoc that still says Rust-only.

**Tests:** Live ChromeDriver + DriverConstruction.ready() + composite find/click through real adapter. Unit tests for lookup order. Fallback log assertion.

**CLI-first / logging:** New attach behavior reachable via domengine CLI. Logging toggleable.
