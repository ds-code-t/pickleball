## E2 — Embedded store backend behind `DoltStore` (about 3 to 4 days)

**Functionality**
- `DoltStore`, `DoltSession`, `DoltConnections` and `Binding` open SQLite files (design section 6.1): `main.db`, `runstate.db`, `sandboxes/<name>/source.db`. Pragmas, pool, `BEGIN IMMEDIATE`, busy retries and `error: concurrent update on <table>` per design section 9.
- `DoltDialect` ported back to SQLite: every statement in `DoltDialect.statements()` and the inventory. `AUTO_INCREMENT` to `INTEGER PRIMARY KEY AUTOINCREMENT`, `LONGBLOB` to `BLOB`, `ON DUPLICATE KEY UPDATE` to `ON CONFLICT … DO UPDATE SET col = excluded.col`, `INSERT IGNORE` to `INSERT OR IGNORE`, `information_schema.columns` to `pragma_table_info`, `CAST(… AS SIGNED)` to `CAST(… AS INTEGER)`, `GET_LOCK` and `FOR UPDATE` removed. `concat()` stays (SQLite 3.44+). Never `||` in filter fragments, as today.
- Run-state router: pure run-state statements on a `runstate.db` session; joined statements on the source session with `runstate.db` attached read-only (design 6.6). The cross-file `definition_id` foreign key becomes the existing null-if-missing rule in code.
- Schema version: a fresh store writes `store_schema=1` and keeps `schema_version=1`; `dolt_schema` is no longer written. Change-log table and generated triggers (design 8.1). `hydrate_generation` and `hydrate_label` in `schema_meta`.
- The Dolt server path stays in the tree but is no longer used by the store (removed in E6).

**Docs:** design section status lines updated to "E2 implemented"; `AGENTS.md` `## Dolt` paragraph for the store driver and files (edit only that paragraph).

**Tests**
- Ported: `DoltDialectInventoryTest`, `DoltDialectTrapsTest` (new traps: upsert on a view refused, `FOR UPDATE` refused, BLOB in `json_object` refused, `||` still absent from filters), `DoltSchemaTest`, `DoltSchemaUpgradeTest`, `DoltFoundationTest`, `DoltConcurrencyTest` (multi-process, no lost update), `DoltDriverMissingTest` (message names `sqlite-jdbc`).
- New: `tools.dscode.dolt.store.ChangeLogTriggerTest` (every logged column appears; a BLOB column without a hash column fails the guard), `tools.dscode.dolt.store.RunStateRouterTest`.

**Port table (fill in notes):** `DoltJdbcBranchSpikeTest` → `EmbeddedStoreSpikeTest`; MySQL-only trap assertions → SQLite trap assertions, one for one.
