## Phase 1 — Critical bugs (B1, B4, B5, B2/P3, B14, B16)

**Functionality:**
- B1: guard `raiseLayer` against re-entry and ignore layer-originated `toggle` events in `pkb-runtime.js`. Selftest CPU assertion.
- B4: on worker stop/restart call `WebDriver.quit()` and `ProcessTrees.killTree`; emit `browser_lost`.
- B5: document the 120s/30s lease; hold the pause while any client (MCP or CLI) is attached via heartbeat; emit session-ended event. `--hold` available.
- B2/P3: CLI agent verbs POST to the live worker's `/v1/agent/command` when a session exists; fail fast with `error: no live browser` otherwise. No second transport.
- B14: quote `"-Dmdep.includeScope=test"` in the generated PowerShell opener; include `target/classes` and `target/test-classes` on the fallback classpath.
- B16: flag empty consumer glue as `noop:true` on step replies and warn in the run report by default. Opt-in may turn it into a failure.

**Docs:** rewrite relevant sections in place (`docs/consumer-agent-guide.md`, `docs/pickleball-workbench.md`, `docs/dynamic-control-api.md`, release-notes).
