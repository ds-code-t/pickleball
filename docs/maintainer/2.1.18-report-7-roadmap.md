## Root-cause analysis (verified in code @ a4c7ea6f)

### A. Run-id workspace resolver (bugs 1, 3)
**Root cause:** isolate --run-id and validate --run-id do not load the requested run's workspace/glue. They fall back to the most recently discovered/seeded workspace (or project default). Session descriptor shows correct runId but wrong workspacePath. Validate ignores --run-id for glue loading (always scans src/test/java etc.).
**Fix direction:** One shared Workspace.forRunId(project, runId) (or latest snapshot only when no run-id given). Print which workspace was loaded. Load pkb_glue from that workspace for validate and isolate.
**Regression risk:** All isolate/validate/discover/confirm paths, session descriptor, multi-run consumers. Locking tests: new multi-run consumer scenarios; existing Workspace/seed tests.

### B. Validate matching (bug 2)
**Root cause:** WorkbenchValidate uses ExpressionFactory.createExpression, but regex step defs (^...$) are not matched (357 undefined on whole suite that passes at runtime). Plain Cucumber expressions match. Likely ANNOTATION extraction misses regex forms, or createExpression fails (caught and ignored) for some patterns, or glue not loaded from the run's compiled/workspace glue.
**Fix direction:** Build matchers with Cucumber's expression factory (which treats ^...$ as regex). Ensure all glue (including from selected workspace/pkb_glue) is captured and compiled. One matcher shared with the runner.
**Regression risk:** validate command, feature index. Locking tests: new regex + expression fixtures in consumer_sim; existing validate tests.

### C. Validate cap (bug 4)
**Root cause:** STEP_CAP = 2000 hard-coded. Whole-suite stops with capped:true. help validate offers no --max-steps, --all, or paging. No report of skipped scenarios.
**Fix direction:** Add --max-steps=<n> / --all. Report how many scenarios were skipped. Keep progress.
**Regression risk:** validate whole-suite. Locking tests: consumer_sim >2000 steps scenario.

### D. Status before first step (bug 5)
**Root cause:** Right after isolate (nothing queued), status prints status=running and elapsed-step-ms=N. After a step it prints idle. Source reports running before any command is in flight.
**Fix direction:** Report idle whenever no command is in flight. Fix at the health/session state source.
**Regression risk:** status, session lifecycle. Locking tests: consumer_sim status right after isolate.

### E. --quiet output (bug 6)
**Root cause:** --quiet drops only the console: line. Docs say it keeps the summary and drops everything else, but 9 lines remain (workspace-runvars, retained pkb_run_profile, NEXT:, etc.).
**Fix direction:** Print only the summary (and error:/fix:). Update docs if behavior changes.
**Regression risk:** All launch output paths (direct/warm/wrapper). Locking tests: consumer_sim --quiet line budget.

### F. startup-progress.json (bug 7, regression)
**Root cause:** Each new start's file begins with the previous session's last stage at 0s (e.g. index-end@0s). This was fixed in a4b87f2 but regressed.
**Fix direction:** Truncate the file when a session start begins.
**Regression risk:** session start, timing. Locking tests: consumer_sim repeated starts assert clean file.

### G. Restart speed (bug 8)
**Root cause:** Every live-session start is slow (89-116s). 80-90s pass between index-end (~2s) and jvm with no stage reported. Earlier builds: 32s (a4b87f2), 48s (dae708e). Restarts regressed.
**Fix direction:** Report what runs between index-end and jvm. Skip it when classpath and compiled classes are unchanged since last start/discover. Target warm restart <= ~35s.
**Regression risk:** isolate restart, classpath cache, timing. Locking tests: consumer_sim restart timing budget.

### H. failedScenarios paths (bug 9)
**Root cause:** Entries use absolute file:///C:/... URIs (~150 chars). Machine-specific; differ from project-relative path:line that plan and validate print.
**Fix direction:** Use the same project-relative path:line as plan.
**Regression risk:** failure reports, summary. Locking tests: consumer_sim failedScenarios format.

### Shared-path fix (after `b08f16c7`)

Jar identity is path, size, and mtime (`jar-hashes.v1`).
