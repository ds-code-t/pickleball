## Decisions
Shared test helpers live in `src/testSupport/java` and are compiled into each module's test source set. They are not protocol main code and they are not a published fixture. Each module compiles its own copy. A child JVM is started with that module's test classes directory on the classpath, and the Java launcher uses an argument file, so the Windows command line stays short.

POSIX execute bits are set only when `PosixFileAttributeView` is present. Windows launchers are `.cmd` files. Tests do not call `Files.setPosixFilePermissions`. No Python.

Assumption guards: none.
