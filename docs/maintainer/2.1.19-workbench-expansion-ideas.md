# Workbench expansion ideas (2026-11-06)

Source: Dan Shell, voice call 2026-11-06 about 12:40 AM America/Phoenix.
This document is source material for a Grok Heavy brainstorm. It is not an implementation order and not a locked roadmap.

## End goal

The Workbench should let AI agents fully take control of browsers -- multiple windows, tabs, and everything they need -- including writing HTML on the fly into pages.

## Ideas

1. Live chat panel where AI agents and human users exchange messages through the Workbench.
2. Pop-ups and overlays rendered over browser content to guide humans -- for example "click here" or explanations of what something does -- placed directly on elements.
3. The same HTML surfaces should accept user input back to the agent.
4. Dynamic CSS changes on elements at runtime to highlight them (for example a yellow highlight) with predefined helper methods rather than ad-hoc scripts.
5. Predefined browser launch templates for Chrome, Edge, and other Chromium browsers -- headless and non-headless, with and without logs -- startable on the fly, either as-is or with slight on-the-fly modifications.
