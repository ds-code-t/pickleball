## Inefficiencies that are not code bugs

| Item | Disposition |
|---|---|
| Maven exec 10–20 s | Closed as the warm path. `export-guidance --warm`, then `java -cp @classpath.cache`. Second controller ping ≤ 1 s. |
| `isolate` about 50 s and a multi-hundred-MB copy | Documented limitation. Isolate still copies a workspace. A live browser should use `start`, not `isolate`. |
| MCP worker start / restart 25–37 s | Documented limitation of the worker path. The agent controller removes a new JVM per CLI verb. Restarting a Workbench worker is unchanged. |
| Inspect replies 8–25 KB | Closed by the compact lines view and `--fields` / `--budget`. |
| `workbench_browser_page` about 100 KB | Documented limitation of that tool. Use `snap` or `inspect-page` for a short reply. Full HTML stays opt-in. |
| Screenshot base64 about 128 KB | Closed earlier. `screenshot --out=<file>` writes the PNG and does not inline base64. |
| `chat-history` / `chat-poll` without a cursor | Closed earlier. The cursor is armed at session start, and the same token reads the same position again. |
| CLI needed a hand-written MCP client | Closed. `call` plus the controller. |
| XPath-only category warning and 0 matches | Documented limitation. A consumer category that is only an XPath still warns and can match nothing in a layout the XPath does not describe. |

## Verification

Recorded on `3.0.0-regression` (cut from `cf9fe428`). Version stays 3.0.0. Not merged to master. Scoreboard: [3.0.0-regression-scoreboard.md](3.0.0-regression-scoreboard.md).

Targeted tests and guidance contracts were re-run on JDK 21. Root filter: 100 tests, 92 passed, 2 failed, 6 skipped. The two failures and the six skips are `start` / Chrome cases with no binary on `PATH` (`error: unsupported --browser=chrome` or an explicit skip). `NoopGlueReportTest`, `NoopGlueFlagTest`, and `ControlBridgeNativeStepTest` passed. `scripts/verify_agent_contract.py`, `scripts/sync_consumer_guidance.py --check`, and `scripts/refresh_agent_index.py --check` passed.

`maven-consumer-project` non-browser suite (`@all and not @browser`, `pkb_parallel=1`): 349 scenarios. `LazyBooleanSideTest` 17 passed. The guidance scenario failed until `PickleballGuidanceChecks` followed the short-guide / detail-guide split (`37094e88`); it passes now. Every remaining failure is `cannot find Chrome binary`. `@browser` was not run. No envelope, short-id, no-op glue, frame-reporting, or composite-verb failure.

Documented limitations still match the code and the consumer docs:

- B10. There is still no `inspect --frames=all`. `help frame` says `--enter` scopes later find, act, snap, and inspect. Enter the frame, then inspect.
- B13. With composite not primary, `ElementOperations` reads `text=` and `role=` from the top document and does not walk shadow roots or iframes. `near=`, `below=`, and `above=` still have no layout box. Release notes, agent-fast phase 7, say the same thing.
- B15. `isolate` on a new run id with no workspace prints `error: no workspace for run id` and `fix: Run workspace-seed or discover for that run id.` A live browser uses `start`, not `isolate`.
- Isolate still materializes a workspace (`copy-base` / `copy-live`). That cost was not re-timed here.

The first-read guide is 5052 UTF-8 LF bytes (limit 5120) and still lists `start --url-key`, `chat-turn`, `act --query`, `ui-verify`, and `doctor`. The long-form frame and composite-off wording stays in `docs/workbench-agent-detail.md` and the release notes.

## Roadmap 2 (failing verbs)

N18 `execute-steps`. Closed on this branch. Page verbs inside the file post to the live worker (same path as a direct verb). `doctor` runs in this process and is not `unknown agent command`. `stopped` is true only when `--stop-on-fail` stops the file. A failure without that flag says `steps failed`. Scoreboard: [3.0.0-roadmap-2-scoreboard.md](3.0.0-roadmap-2-scoreboard.md).

N19 `chat-turn`. Closed on this branch. The HTTP budget is the verb timeout plus 15 seconds (cap 180), including the MCP control-bridge client. A worker pid that is still alive reports `timeout`, not `live worker unreachable`. The person's message is listed once.

Live/headed path: a separate environment confirmed that Google Chrome 148 is present and launches. This host has no Chrome on `PATH`, so no headed launch was attempted. Full launcher end-to-end (`live-start`, panel, `chat-turn`, `events --follow`) needs a normal Gradle build with toolchain network access and is being verified outside this roadmap. Those results are not in this file yet.
