## 1. Source tracking for every hook-written key

Track the source of every key a runner hook writes, not only `pkb_` keys. A key written with `PKB_props.put` or any setter (`glue`, `features`, `configPath`, ...) shows `source=hook` and ` computed` in `workspace-show` text and `--json`.

- Cause: `PickleballRunner.noteHookWrite` and `valueSources()` filter on `PKB_props.isRunVariableKey`, and `WorkspaceSeed.writeSources` writes a literal `default` for skipped keys.
- Fix: record every non-blank key written while a hook runs, classify every key stored in workspace runvars, and fall back to `inferSource` instead of `default`.
- Tests: a hook that uses `PKB_props.put` for `description`, a `pkb_` key and a secret key next to `glue(...)`, all labeled hook/computed, plus a consumer-sim case.

## 2. Windows exit code docs and stock-wrapper CI test

Correct the Windows docs on usage errors (split `--tags`, unknown verb) through `mvnw exec:java`.

- `java -cp`, `java -jar` and Linux `mvnw` exit 2. The patched wrapper in `maven-consumer-project` also exits 2.
- A stock Maven Wrapper `mvnw.cmd` (any version, including 3.2.0 and 3.3.x) runs Apache `mvn.cmd`, which forces every non-zero status to 1. Say so, and tell Windows scripts to match the `error:` line or use `java -cp` when they need the exact code.
- Add a Windows CI test with a stock wrapper in a temp copy.
- **Open wording to confirm with Dan:** the list says the stock-wrapper test should prove exit 2 passes through. Upstream `mvn.cmd` makes that impossible, so the default is to assert a non-zero exit, `error:` and `fix:` on stderr, and no Maven BUILD FAILURE stack. Change this only if Dan picks another approach (for example shipping the patched wrapper to consumers).

## 3. Comma lists for data path and config path

`pkb_datapath` and `pkb_configpath` accept comma-separated lists, like `pkb_features`, `pkb_componentpath`, `pkb_callpath` and `pkb_glue`.

- Existing single values keep working unchanged.
- A comma always splits paths and never becomes part of a folder name.
- Define list semantics in the docs (for example data: first match wins; configs: merged in order) and test them.
- Prefer one shared splitter for all path settings instead of the current three `split(",")` copies.

## 4. Short RUN type aliases

RUN steps and `RunType` table cells accept `COMPONENT`, `COMPONENTS`, `CALL`, `CALLS`, `SERVICE` and `SERVICES` alongside the full words.

- `COMPONENT`/`COMPONENTS` map to `COMPONENT SCENARIO(S)`; `CALL`/`CALLS`/`SERVICE`/`SERVICES` map to `SERVICE CALL(S)`.
- Singular aliases error when more than one scenario matches; plural aliases allow several, the same as the full words.
- Case rules unchanged: uppercase in step text, uppercased in table cells.
- Full words keep working unchanged.
