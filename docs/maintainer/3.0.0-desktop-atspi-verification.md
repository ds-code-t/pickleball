# 3.0.0 desktop AT-SPI verification

Branch: `3.0.0`. Version stays 3.0.0. `master` was not fetched, merged, rebased, or pushed.

JDK: Temurin 21.0.13.1 at `/opt/jdk-21` (the image JDK is 17). Display: Xvfb `:99` at 1280x800x24. A real session bus and `at-spi-bus-launcher` were started. This is not a fake bus. `busAddress()` calls `org.a11y.Bus.GetAddress`, so a session bus with no accessibility service turns the old skip into a failed walk. Do not do that.

`busctl` is not on this image. It is part of `systemd`, which is not installed. The same check is `dbus-send` `ListNames` on the session bus (`org.a11y.Bus`) and `org.a11y.Bus.GetAddress`. The accessibility bus then lists `org.a11y.atspi.Registry`.

## Setup

`apt` cannot `setgroups` to `_apt`. `man-db` cannot `chown` `/var/cache/man` (`Invalid argument`), so do not install it. `x11-apps` depends on `man-db` and was removed after it blocked later installs. `xwd` went with it. `xmessage` is in `x11-utils` and stayed. ImageMagick `import` and `libxtst6` stayed, so a desktop screenshot still succeeds.

```
printf 'APT::Sandbox::User "root";\n' > /etc/apt/apt.conf.d/99sandbox
mkdir -p /tmp/apt-archives
apt-get update -o Dir::Cache::archives=/tmp/apt-archives
DEBIAN_FRONTEND=noninteractive apt-get -o Dir::Cache::archives=/tmp/apt-archives install -y \
  -o Dpkg::Options::=--force-confold \
  at-spi2-core dbus-x11 imagemagick x11-utils xdotool libxtst6
# If procps stops on /etc/sysctl.conf: dpkg --force-confold --configure procps
# Then: dpkg --configure dconf-service dconf-gsettings-backend gsettings-desktop-schemas at-spi2-core

mkdir -p /tmp/runtime-root
chmod 700 /tmp/runtime-root
export XDG_RUNTIME_DIR=/tmp/runtime-root
Xvfb :99 -screen 0 1280x800x24 -ac +extension GLX +render -noreset >/tmp/xvfb.log 2>&1 &
export DISPLAY=:99
eval "$(dbus-launch --sh-syntax)"
export DBUS_SESSION_BUS_ADDRESS
/usr/libexec/at-spi-bus-launcher --launch-immediately >/tmp/at-spi-bus.log 2>&1 &
sleep 1
dbus-send --session --print-reply --dest=org.a11y.Bus /org/a11y/bus org.a11y.Bus.GetAddress
export JAVA_HOME=/opt/jdk-21
export PATH="$JAVA_HOME/bin:$PATH"
```

`GetAddress` returned `unix:path=/tmp/runtime-root/at-spi/bus_99`. Gradle must be `--no-daemon` so the test worker inherits `DISPLAY` and `DBUS_SESSION_BUS_ADDRESS`.

Packages: `at-spi2-core` 2.46.0-5, `dbus-x11` 1.14.10, ImageMagick 6.9.11.60, `libxtst6` 1.2.3. The launcher is `/usr/libexec/at-spi-bus-launcher`. The registry it starts is `/usr/libexec/at-spi2-registryd`.
