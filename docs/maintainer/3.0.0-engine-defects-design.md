### Architecture note (from tip)

Java DOM engine (`dom-engine`, `dev.domengine`) is the default, general-purpose, bundled. Pickleball locates it via locators; Rust is explicit opt-in. Default element path is through `ElementOperations` → `DomCompositeAdapter` → Java engine when `pkb_composite=auto`. Native engine (`tools.dscode.engine`) is the default (`EngineConfig`); Cucumber adapter remains supported. Dalton is opt-in. Workbench isolation must be preserved. Some earlier design docs (e.g. Phase 12 in `3.0.0-engine-design.md`) still say default stays Cucumber; later `AGENTS.md` appends and `EngineConfig.java` win. Public contracts paragraph in `AGENTS.md` still contains some stale Rust-binary language; source and later appends win.
