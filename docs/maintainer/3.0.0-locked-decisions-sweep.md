## Gaps list

- No single browser facade; Playwright absent; Selenium narrowly pinned; no BiDi.
- Direct CDP is the default element path for scripted tests (reversed from libraries-default).
- No agent-only protocol boundary.
- MCP not the single agent entry point.
- Negative relations and scored label affinity incomplete (only distance sort + Boolean NOT).
- Pre-mapping as core principle missing.
- Universal composite snapshot not combined on any platform (verified by snapshot-coverage-audit.md).
- Dalton remains opt-in (not central).
- Residual Rust override/vendored/natives remain.
- XPath remains primary passthrough.
- Section detection and size-capped one-match incomplete.

## Stale or contradicting doc lines

- AGENTS.md: Dalton opt-in, not central.
- README.md, configuration.md, release-notes.md: Dalton opt-in; Java engine as default element path (contradicts libraries-default and facade).
- docs/maintainer/3.0.0-dalton-design.md: opt-in, files source of truth.
- configuration.md / direct-control-handoff.md: document Rust override.
- custom-element-definitions.md: XPath passthrough.
- Snapshot audit notes: no combined snapshot; DesktopTree not fully live in some docs.
