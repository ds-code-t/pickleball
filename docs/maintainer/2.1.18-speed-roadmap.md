## Shared mechanism

One long-lived worker / controller with:
- Cached resolved classpath (hash of pom.xml + lockable inputs). Skip full Maven when unchanged. Prefer Maven daemon (mvnd) if available; else persistent resolve or pure cache-skip.
- Warm JVM reuse across commands. Invalidate/restart only on classpath or watched source/config change (content hash or mtime+size).
- Stage scheduler for concurrent independent stages. Overlap feature index with compile; overlap seed with compile.
- Failure fallback to today's sequential fresh-JVM path on any cache miss, hash mismatch, daemon error, or parallel failure.
- Identical Windows/Linux behaviour; use project wrappers only.
- One shared process where possible; remove second controller JVM if isolation invariants allow.
