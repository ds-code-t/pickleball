Chrome: Google Chrome 158.0.8127.36. JDK: Temurin 21.0.13.1 at `/opt/jdk-21` (the image JDK is 17; the build toolchain is 21). Display for headed tests: Xvfb `:99` at 1280x800x24. The Gradle daemon must be started with `DISPLAY=:99` or a headed session exits immediately.

## Install (this sandbox)

`apt` cannot `setgroups`/`seteuid` to `_apt`. The Chrome `.deb` also fails its systemd postinst (`Failed to copy permissions from /etc/gshadow`). Extract the package and put the binary on `PATH`. AWT screenshots need `libXtst`.

```
printf 'APT::Sandbox::User "root";\n' > /etc/apt/apt.conf.d/99sandbox
mkdir -p /tmp/apt-archives
# google-chrome-stable_current_amd64.deb (158.0.8127.36-1)
dpkg-deb -x google-chrome-stable_current_amd64.deb /opt/google-chrome-extract
ln -sf /opt/google-chrome-extract/opt/google/chrome/google-chrome /usr/local/bin/google-chrome
ln -sf /usr/local/bin/google-chrome /usr/local/bin/google-chrome-stable
ln -sf /usr/local/bin/google-chrome /usr/local/bin/chrome
apt-get -o Dir::Cache::archives=/tmp/apt-archives install -y libxtst6
Xvfb :99 -screen 0 1280x800x24 -ac +extension GLX +render -noreset &
export JAVA_HOME=/opt/jdk-21
export PATH="$JAVA_HOME/bin:/usr/local/bin:$PATH"
export DISPLAY=:99
export DOMENGINE_CHROME=/usr/local/bin/google-chrome
export CHROME_BIN=/usr/local/bin/google-chrome
export CHROME_BINARY=/usr/local/bin/google-chrome
export PKB_CHROME_BINARY=/usr/local/bin/google-chrome
google-chrome --headless --disable-gpu --no-sandbox --dump-dom https://example.com
```

`BrowserSession.findChrome()` uses `DOMENGINE_CHROME`, then `google-chrome`, `google-chrome-stable`, `chromium`, `chromium-browser`, and `chrome` on `PATH`. Headless dump of `https://example.com` returned the Example Domain page. DBus errors from Chrome are noise.
