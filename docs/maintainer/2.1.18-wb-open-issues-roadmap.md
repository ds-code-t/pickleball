- `stage=copy-base` after outputs→base/classes (file count + bytes + ms)
- `stage=copy-live` after base→live/classes (file count + bytes + ms)

### Phase 1 — A2 log rotation

Reuse `AgentCoordination.archivePreviousAttempt` (or extract a shared next-attempt numbering helper used by discover, see `AgentCoordination.java:1124-1143`) so each isolate of the same run-id rotates the prior `session.log` + `startup-progress.json` pair into `attempts/<n>/` before truncating/writing the new pair. Same numbering as discover. Docs + targeted consumer repro that checks first-start evidence survives a second isolate.

### Phase 2 — A3 no-workspace error surfacing

Surface the last real error (the "no workspace for run id…" that is already written to session.log) as `error:`/`fix:` on the parent, matching discover/confirm style. Prefer a parent pre-check that fails before spawn when the run has no workspace. Alternatively scan new log bytes since `logBaseline` (`SESS:535`). Targeted Windows/PowerShell repro that shows the `error:`/`fix:` without needing to open the log.

### Phase 3 — A4 validate flag rejection

Reject `--quiet` (and any other flag a command does not use) with `error:`/`fix:` for validate. Keep discover/confirm `--quiet` behavior unchanged. Update docs and help. Targeted test that `--quiet` on validate is rejected and that discover/confirm still quiet.

### Phase 4 — Optimize cold materialize (A1+B)

Instrument-first results guide the change. Keep one shared path. Options that preserve invariants (choose the simplest that meets the target):
- `live/classes` as overlay or hardlinks of base (`Files.createLink`, fallback copy) — base stays immutable as long as live writes go to generated-classes.
- Fingerprint base from `(relpath,size,mtime)` or reuse the classpath-cache token instead of reading bytes; content-hash only racy-window files like jars.
- Parallelize the directory walk if needed.

Do not move work into discover. Fresh-cache first isolate <60s. Second start still classpath-cache. Base/classes remains immutable. Targeted consumer_sim + Windows cold-start repro.
