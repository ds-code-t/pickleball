## Phases (EVERY PHASE MANDATORY — nothing optional)

### Phase 0 — Instrument materialize timings (no behavior change)

Add progress stages inside `materialize`: `stage=materialize-copy` (after both copies, with file count + ms), `stage=materialize-hash` (after fingerprint, with class-file count + ms + bytes). Keep existing stage marks. Record consumer_sim cold-isolate and fresh-cache first-isolate timings into the scoreboard. Targeted tests only. No functional change.

### Phase 1 — A2 log rotation

Reuse `AgentCoordination.archivePreviousAttempt` (or extract a shared next-attempt numbering helper used by discover) so each isolate of the same run-id rotates the prior `session.log` + `startup-progress.json` pair into `attempts/<n>/` before truncating/writing the new pair. Same numbering as discover. Docs + targeted consumer repro that checks first-start evidence survives a second isolate.

### Phase 2 — A3 no-workspace error surfacing

Surface the last real error (the "no workspace for run id…" that is already written to session.log) as `error:`/`fix:` on the parent, matching discover/confirm style. Prefer a parent pre-check that fails before spawn when the run has no workspace. Targeted Windows/PowerShell repro that shows the `error:`/`fix:` without needing to open the log.

### Phase 3 — A4 validate flag rejection

Reject `--quiet` (and any other flag a command does not use) with `error:`/`fix:` for validate. Keep discover/confirm `--quiet` behavior unchanged. Update docs and help. Targeted test that `--quiet` on validate is rejected and that discover/confirm still quiet.

### Phase 4 — Optimize cold materialize (A1+B)

Instrument-first results guide the change. Keep one shared path. Options that preserve invariants: skip full class-file digest when the classpath-cache hit already proves the outputs unchanged and base/classes is already present; or hash only the delta; or parallelize the directory walk. Do not move work into discover. Fresh-cache first isolate <60 s. Second start still classpath-cache. Base/classes remains immutable. Targeted consumer_sim + Windows cold-start repro.

### Phase 5 — Docs, scoreboard, contracts

Update `pickleball-workbench.md`, release-notes, any CLI help, and this roadmap with measured numbers. Fill scoreboard. Verify agent contract. STOP after the implementation push and report the head SHA. Full regression only on explicit continue.
