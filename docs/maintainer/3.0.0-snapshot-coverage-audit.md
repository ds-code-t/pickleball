# Composite snapshot coverage on origin/3.0.0

Inspected 2026-11-13, America/Phoenix, after G3 Phases 5–8. Every platform writes one composite snapshot. The earlier gap, a missing combined artifact, is closed.

A composite snapshot is the page-level artifact (`schema` `pickleball.composite-snapshot`): screenshot, source, structure, XPaths or platform paths, a viewport map, and a pre-map. The pre-map is core. The per-element capture is an element snapshot (`ElementSnapshot`), not this artifact.

## CI

`.github/workflows/agent-contract.yml` still has the `windows`, `dom-engine-live`, and `gate` jobs. The added steps are:

- `windows`: Windows UIA live snapshot (`SnapshotCoverageTest.liveDesktopWhenThePlatformExists`).
- `dom-engine-live`: Linux desktop live snapshot under `xvfb-run` after installing `at-spi2-core`, `xvfb`, and `imagemagick`; Edge live snapshot; Firefox live snapshot.

No job was removed. The run id for the SHA that added those steps is recorded on the G3 scoreboard.

## Gaps that are not missing artifacts

- `stableSelector` on an element snapshot is CSS, not the page XPath.
- `LiveTree.enrich` remains the per-node path used by actions, not by the snapshot.
- macOS live AX has no hosted runner. The fixture row above is what CI runs.
