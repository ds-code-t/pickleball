# PKB-HCR — pickleball Human Collaboration Regression

**PKB-HCR** is the tag for the manual human-collaboration regression: 75 agent-run tests, stable ids HCR-01 through HCR-75.

After a successful `export-guidance`, load `.pickleball/AGENT-GUIDE.md` first, then the full catalog at `.pickleball/PKB-HCR.md`. The results template is `.pickleball/PKB-HCR-scoreboard.md`. Inside the published jar those files are `META-INF/pickleball/guidance/PKB-HCR.md` and `META-INF/pickleball/guidance/PKB-HCR-scoreboard.md`.

Invoke with `Run PKB-HCR` (the whole catalog), `Run PKB-HCR HCR-12` (one test), or `Run PKB-HCR paired only`. The whole catalog runs only when the project owner explicitly asks.
